# ערכת מבדק מקוון בסגנון תנופה

גיליון Google אחד שהוא גם בסיס הנתונים וגם הכלי: התלמידות עונות על אתר, המורה בודקת בלוח עם כוכבים, הבינה המלאכותית מציעה ניקוד לפתוחות, והתלמידות רואות משוב מפורט עם קוד אישי. הכול נשמר בגיליון של המורה.

## מה מקבלים
- מבחן בשלוש יחידות עם קטעי קריאה, טבלאות, גרפים ואיורים. שאלות סגורות, השלמה, טבלאות ופתוחות.
- כמה נוסחים (א, ב, מועד ב עם קוד גישה). סדר התשובות מתערבב לכל תלמידה. אי אפשר להדביק בשדות הכתיבה.
- לוח מורה: בדיקה לפי שאלה או תלמידה בכוכבים, תמונה כיתתית (ציונים, שאלות קשות, מסיחים), טבלה ממיינת ומסננת, פרסום משוב.
- **תוכן המבחן בגיליון**: בלשונית "שאלון". כותבים אותו עם בינה מלאכותית ומדביקים (ראו שלב 2).
- **הצעות ניקוד**: מפתח API של Google AI Studio בתא הצהוב. נשלחות רק התשובות, בלי שמות.

## שלבים למורה
1. **שכפול.** פותחים את קישור ההעתקה שקיבלת ולוחצים "יצירת עותק". העותק כולל את הסקריפט.
2. **התקנה ותוכן.**
   - בתפריט "מבדק" בגיליון: **התקנה ראשונה** (אישור הרשאות חד-פעמי).
   - לשונית "שאלון" מכילה מבחן לדוגמה (מבדק התא). כדי להחליף: נותנים ל-Gemini או ל-Claude את הסקיל `tnufa-exam-author` (או את `gem-instructions.md` כ-Gem), מתארים נושא וכיתה, ומדביקים את התוצאה בתא A2 (אחרי מחיקת השורות הישנות).
   - בתפריט: **בדיקת תקינות השאלון**.
3. **פריסה.** תוספות > Apps Script > פריסה > פריסה חדשה > סוג: אפליקציית אינטרנט > הפעלה בתור: **אני** > גישה: **כל אחד** > פריסה. מאשרים הרשאות. אחרי הכניסה הראשונה לכתובת, הכתובת מופיעה בלשונית "התחלה" בגיליון.
4. **בדיקה והצעות ניקוד.**
   - ב-[Google AI Studio](https://aistudio.google.com/apikey) יוצרים מפתח API (בחשבון הארגוני) ומדביקים בתא הצהוב בלשונית "הגדרות". לא בשום מקום אחר.
   - תפריט: **בדיקת חיבור ל-Gemini**. אחר כך בלוח המורה: כפתור **הצעות ניקוד מ-Gemini**.
   - בדיקת הכלי: נכנסים לכתובת התלמידות, מסמנים "אני מורה" ועונים. הנתונים נשמרים בכיתת הניסוי, ואפשר למחוק אותם מהתפריט.
5. **מסירה.** כתובת התלמידות מתוך "התחלה". תלמידות כותבות שם פרטי ואות משפחה, כיתה (אות וספרה), ובוחרות נוסח.

## פרטיות
- נתוני התלמידות נשמרים רק בגיליון של המורה.
- אל Gemini נשלחים ניסוח השאלה, התבחינים והתשובה, בלי שם וכיתה.
- חשבון ארגוני מוגן מאימון: זה תנאי. ב-AI Studio בשכבה החינמית ייתכן שהנתונים משמשים לשיפור מוצרים: להשתמש בחשבון ארגוני, או בפרויקט עם חיוב.
- מפתח המורה (בלשונית "התחלה") נותן גישה ללוח הבדיקה: לא לשתף.

## בעיות נפוצות
- "הגישה נדחתה" בכתובת: לא הושלמה ההתקנה או האישור, או שהפריסה לא על "כל אחד".
- אחרי שינוי בשאלון: מרעננים את דף התלמידה. שינוי בשאלון באמצע מבחן משפיע על תלמידות שעוד לא התחילו.
- Gemini נכשל: בודקים את המפתח, ובתפריט "בדיקת חיבור" רואים את הדגמים הזמינים. אפשר להחליף את "דגם Gemini" בהגדרות.

## למי שבונה את הערכה (מפתחות)
- `Content.gs` מפענח את הגיליון, `Code.gs` השרת, `Setup.gs` ההתקנה והחיבור ל-Gemini, `Sample.gs` תוכן לדוגמה, `Index.html`, `Teacher.html`, `Result.html` הדפים.
- `tools/test-kit.js` בודק את כל השרת מול גיליון מדומה: `node tools/test-kit.js`.
- `tools/export-sample.js` מייצא את מבדק התא ל-`Sample.gs` ובודק שהפענוח מדויק.
- פריסה לגיליון תבנית: `clasp create --type sheets`, ואז לשחזר את `appsscript.json` (clasp דורס אותו), `clasp push`.
